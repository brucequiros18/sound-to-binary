    Explain it

    1. How my app turns a wave into binary. It samples the wave’s height at equal time steps across one full period, rounds each height to the nearest level, then writes every level in binary using the chosen bit depth.
    2. Test A with 2 bits vs 6 bits. 6 bits gives more detail because it has 64 levels instead of 4, so the binary follows the wave’s height more closely — it also uses more bits for the same number of samples.
    3. Longest wavelength. Test B (200 Hz) has the longest wavelength, because wavelength = 343 ÷ frequency, so a lower frequency means a longer wavelength.
    4. Hardest stage. The hardest stage was the binary stage, because a height exactly halfway between two levels must round up; I fixed it by comparing my table with the given example and correcting the rounding until every row matched.
